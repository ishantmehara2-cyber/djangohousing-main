# Property Owner Guide

## Listing a Property
1. Register as a Property Owner.
2. Click **+ Post Property** in the navigation header.
3. Complete the multi-step form: basic details, pricing, area, amenities, and photo uploads.
4. Save as draft or submit for admin approval.

## Managing Leads & CRM
- Access your Owner Dashboard to view incoming enquiries and CRM leads.
- Update lead status (New, Contacted, Visit Scheduled, Converted) and record notes.
