# Platform Administrator Guide

## Admin Panel (`/admin-panel/`)
- **Property Moderation**: Review pending properties, approve or reject with reasons.
- **User Management**: Activate/suspend user accounts and toggle identity verification.
- **Reports & Flagged Listings**: Investigate user reports and take moderation actions.
- **Support Tickets**: Manage customer support requests and communicate with users.
- **Audit Logs**: Monitor sensitive administrative actions.
