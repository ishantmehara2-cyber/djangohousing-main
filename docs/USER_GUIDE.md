# User Guide (Buyers & Tenants)

## Searching for Properties
- Use the homepage search bar or browse Buy / Rent / Commercial categories.
- Apply filters for location, budget, BHK, and furnishing.

## Favourites & Comparison
- Click "Save Property" on any listing card to add to favourites.
- Use Property Comparison to compare side-by-side specs.

## Enquiries & Site Visits
- Submit enquiries or schedule site visits directly from property detail pages.
- Track enquiry status and notifications in your buyer/tenant dashboard.
