# Project Overview: Housing.clone (Django Edition)

Housing.clone is a production-grade, feature-complete real estate marketplace inspired by Housing.com. Built with **Django 5**, **Django Templates**, **MySQL**, and **Vanilla JavaScript/Tailwind CSS**, the platform provides a robust ecosystem for buyers, tenants, property owners, real estate agents, and platform administrators.

## Core Pillars
1. **Multi-Role Marketplace**: Tailored user dashboards for Buyers, Tenants, Property Owners, Agents, and Administrators.
2. **Advanced Search & Discovery**: Filter properties by city, locality, budget, BHK, property type, furnishing, and intelligent recommendations.
3. **Trust & Safety**: Property reporting, moderation queue, admin verification, and secure audit logging.
4. **CRM & Lead Management**: Comprehensive lead tracking, activity logs, and follow-up reminders.
5. **Monetization & Subscriptions**: Packages, Razorpay integration, invoices, and featured property promotions.
